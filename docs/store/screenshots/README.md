# Screenshots

Esta carpeta está reservada para las capturas de pantalla de la ficha de la Chrome Web Store.

## Especificaciones

- Tamaño: **1280×800 px** o **640×400 px** (recomendado 1280×800)
- Formato: PNG o JPEG
- Mínimo: 1 captura
- Máximo: 5 capturas
- Sin texto promocional engañoso
- Capturas reales de la extensión funcionando, no mockups

## Capturas recomendadas

Ver `../listing.md` para los detalles completos. Resumen:

1. `01-popup-enabled.png` — Popup con la extensión activada
2. `02-popup-disabled.png` — Popup con la extensión desactivada
3. `03-options.png` — Página de opciones con estadísticas
4. `04-notification.png` — Notificación nativa tras limpieza (opcional)
5. `05-in-use.png` — Flujo en uso (opcional)

## Cómo tomarlas

1. Carga la extensión en modo desarrollador
2. Navega a sitios con cookies de terceros (cualquier sitio con trackers)
3. Espera unos segundos para que se acumulen cookies
4. Toma capturas de las pantallas reales

No hay que generar nada en esta carpeta automáticamente — son capturas reales del uso.
